=======
#### Интеграция с QUIK
1) Склонируйте необходимые репозитории:
   - `git clone https://github.com/WISEPLAT/QuikPy`
   - `git clone https://github.com/WISEPLAT/BackTraderQuik`
2) В QUIK -> Сервисы -> Lua скрипты -> Добавить -> выберите `lua/QuikSharp.lua`.
3) Запустите скрипт (рекомендуется Lua 5.3.5).

### Наработки по BackTrader

#### Почему стоит использовать форк BackTrader от WISEPLAT?
Этот форк содержит важные исправления для совместимости с Python 3.11+ (замена `collections.Iterable` на `collections.abc.Iterable`) и улучшения для темной темы.

Установка:
`pip install git+https://github.com/WISEPLAT/backtrader.git`
